# web-dhcp — веб-панель клиентов DHCP-сети

Это страница со всеми клиентами сети, которым dnsmasq выдаёт адреса по DHCP. На ней видно, кто сейчас в сети,
кто загружается по PXE, у кого BMC (IPMI), а также производитель по MAC. Строкам можно давать подписи.
Сервер написан на Python 3 только со стандартной библиотекой. При желании `start.sh` сам поднимет и DHCP-сервер
(dnsmasq) на нужном интерфейсе.

## Быстрый старт

На Debian 10, 11, 12 или 13 (можно на голую систему):

```bash
git clone <этот репозиторий> web-dhcp && cd web-dhcp
cp .env.example .env     # по желанию: поправить значения по умолчанию (все настройки - в этом файле)
sudo ./start.sh
```

Скрипт покажет сетевые интерфейсы и задаст вопросы: какой интерфейс, порт, поднимать ли DHCP, диапазон адресов,
шлюз, DNS и т. д. Значение по умолчанию показано в скобках, Enter его принимает, а `-` оставляет поле пустым.
Затем скрипт сам:

- поставит недостающие пакеты (`python3`, `python3-venv`, `iputils-ping`, при необходимости `dnsmasq`).
  На Debian 10 он переключит apt на `archive.debian.org`;
- если DHCP ещё нет, поднимет его на выбранном интерфейсе:
  - назначит интерфейсу постоянный адрес, если адреса у него нет (ifupdown, systemd-networkd или NetworkManager);
  - создаст `/etc/dnsmasq.d/<служба>.conf` с диапазоном, сроком аренды, шлюзом и DNS, по желанию — с опцией 60
    «PXEClient» для proxyDHCP (например, iVentoy);
- если dnsmasq уже раздаёт адреса, его конфиг не тронет, а только подключит свой хук (`dhcp-script`);
- скопирует программу в папку установки (по умолчанию `/opt/web-dhcp`) и создаст там **виртуальное окружение
  `venv`**: служба, хук и чистка запускаются только из него;
- создаст и запустит службу systemd и таймер чистки, проверит, что страница отвечает, и покажет адреса.

```bash
sudo ./start.sh -y                  # без вопросов (значения по умолчанию или из прошлой установки)
sudo ./start.sh --answers my.env    # ответы из файла (KEY=VALUE, ключи как в .env.example)
sudo ./start.sh --uninstall         # убрать службу, таймер и свои конфиги dnsmasq; история клиентов остаётся
```

**Обновление:** взять новую версию (`git pull`) и снова запустить `sudo ./start.sh`. Ответы по умолчанию возьмутся
из `.env` прошлой установки.

## Возможности

- Таблица клиентов: подпись, тип, IP, MAC, производитель, hostname, vendor class, «в сети», окончание аренды,
  последний DHCP-запрос, когда клиент появился впервые.
- **Тип клиента:**
  - `BMC / IPMI` — отвечает на IPMI ping (UDP 623, опрос раз в минуту). IP у такого клиента — ссылка на его веб-интерфейс;
  - `PXE boot` — vendor class `PXEClient…`;
  - `OS` — любой другой vendor class.
- **«В сети»** определяется по ARP-таблице интерфейса DHCP-сети.
- **Производитель** берётся по OUI из `oui.tsv` (полная база IEEE). Для частых производителей есть короткие имена.
- **Подписи:** щелчок по ячейке «Имя» задаёт подпись для MAC. Подписи хранятся в `StateDirectory` службы
  (`/var/lib/private/<служба>-labels/labels.json`).
- **Сортировка** по щелчку на заголовок: ▲ → ▼ → исходный порядок. IP и даты сортируются как числа.
  **Фильтр «Только те, что в сети»** включён по умолчанию. Состояние сортировки и фильтра хранится в браузере,
  поэтому переживает автообновление раз в 15 секунд.
- В шапке по желанию: адрес сервера, ссылка на его IPMI, статус iVentoy (если он стоит на этом сервере),
  ссылка на общую папку (например, [web-share](../web-share)).
- **Чистка:** таймер раз в 5 минут забывает клиентов, которых не было в сети дольше `DASH_PRUNE_HOURS`.
  Перед тем как забыть клиента, пингует его ещё раз.

## Настройки — `.env`

Все настройки с комментариями перечислены в **`.env.example`**. Чтобы задать свои значения по умолчанию, скопируйте
его в `.env` (`.env` указан в `.gitignore`). `start.sh` берёт значения в таком порядке: `--answers` → `.env` прошлой
установки → `.env` проекта (а если его нет, `.env.example`) → встроенные (многое определяет сам: интерфейс, подсеть, iVentoy).

Рабочий файл — `<папка установки>/.env`, его читают служба, хук dnsmasq и чистка. После ручной правки:
`sudo systemctl restart web-dhcp`, или снова запустить `start.sh`.

| Ключ | По умолчанию | |
|---|---|---|
| `DASH_PORT` / `DASH_BIND` | `8080` / `0.0.0.0` | порт и адрес |
| `DASH_IFACE` | — | интерфейс DHCP-сети (ARP — «в сети»; пусто — все интерфейсы) |
| `DASH_LEASES` | `/var/lib/misc/dnsmasq.leases` | файл аренд dnsmasq |
| `DASH_HOSTS_DIR` | `/var/lib/web-dhcp/hosts` | история клиентов (пишет хук) |
| `DASH_TITLE` | `Сеть <подсеть>` | заголовок |
| `DASH_SERVER_ADDR` | адрес основного интерфейса | «Сервер: …» в шапке (пусто — не показывать) |
| `DASH_IPMI_URL` | — | ссылка «IPMI сервера» |
| `DASH_IVENTOY_PORT` | `26000`, если iVentoy найден | блок статуса iVentoy (пусто — нет) |
| `DASH_SHARE_URL` | `http://{host}:8081/`, если порт занят | ссылка «Общая папка»; `{host}` — адрес, по которому открыта страница |
| `DASH_SMB_PATH` | — | путь Samba-шары рядом со ссылкой |
| `DASH_PRUNE_HOURS` | `24` | через сколько часов вне сети забывать клиента (0 — никогда) |
| `DASH_PROBE_INTERVAL` | `60` | как часто опрашивать IPMI, секунд |
| `INSTALL_*` | | для `start.sh`: папка, служба, параметры DHCP (диапазон, аренда, шлюз, DNS, PXE); программа их не читает |

Те же ключи можно передать переменными окружения, они важнее файла.

## Откуда берутся данные

| Источник | Что даёт |
|---|---|
| файл аренд dnsmasq | активные аренды: IP, MAC, hostname, срок |
| `DASH_HOSTS_DIR/*.json` | история от `pxe-dhcp-hook` (dnsmasq `dhcp-script`): vendor class, когда впервые и когда последний раз |
| `/proc/net/arp` | кто сейчас в сети |
| UDP 623 | IPMI ping, чтобы найти BMC |
| `http://127.0.0.1:<порт>/iventoy/json` | статус iVentoy (если задан порт) |

## Файлы

```
start.sh            установка / обновление / удаление
.env.example        все настройки с комментариями (скопировать в .env)
pxe-dash.py         веб-сервер + страница, GET /api (JSON), POST /api/label
pxe-dhcp-hook       dhcp-script для dnsmasq
pxe-dash-prune      чистка давно не появлявшихся клиентов (--dry-run — только показать)
oui.tsv             база производителей "XXXXXX<TAB>Название"
tools/make-oui.sh   пересобрать oui.tsv из /usr/share/hwdata/oui.txt (или указанного oui.txt)
```

После установки: `<папка установки>/{pxe-dash.py, pxe-dhcp-hook, pxe-dash-prune, oui.tsv, venv/, .env}`,
`/etc/systemd/system/<служба>.service`, `<служба>-prune.{service,timer}`, а также `/etc/dnsmasq.d/<служба>.conf`
(свой DHCP) или `<служба>-hook.conf` (только хук).

## API

- `GET /api`: JSON-массив клиентов: `mac, label, ip, kind, vendor_class, hostname, vendor, online, lease, expires, last_seen, first_seen`.
- `POST /api/label` `{"mac": "aa:bb:…", "label": "текст"}`: задать подпись. Пустая строка убирает подпись.

Требования: Python 3.7+ (Debian 10+), systemd, dnsmasq.
